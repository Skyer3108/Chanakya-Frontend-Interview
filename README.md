# CivicLens: Parliamentary Constituency Dashboard

The React dashboard application is in [`frontend/`](./frontend/).

## Run locally

Open a terminal in `frontend/` and run:

```sh
npm install
npm run dev
```

Run checks from the same directory:

```sh
npm run lint
npm test
npm run build
```

All project dependencies and the npm lock file are managed inside `frontend/`. No root-level `node_modules` installation is needed.

See [`frontend/README.md`](./frontend/README.md) for data notes and details about the dashboard.
